빛의왕국 탐사맵 편집기

개인 계정으로 로그인하면 프로젝트와 편집 내용이 Supabase에 저장되고, 같은 프로젝트의 변경사항이 실시간으로 공유됩니다.

아이디는 이메일 주소를 사용합니다.
프로젝트
프로젝트를 선택하면 현재 작업 중인 사용자들과 같은 데이터로 전환됩니다.
bot_area SQL 내보내기
현재 프로젝트의 '지역' 데이터를 bot_area 테이블용 INSERT문으로 만듭니다. 생성 전에 검증해서 오류가 날 행(길이 초과·이모지 등 4바이트 문자·숫자칸 오류)은 제외하고 아래에 리포트로 알려줍니다.
📖 SQL 내보내기 사용법
DB가 처음이어도 괜찮아요. 아래 순서대로만 하면 됩니다.
이게 뭔가요?
편집기의 '지역' 데이터를 데이터베이스(bot_area 테이블)에 넣을 수 있는 SQL 문장으로 만들어 줍니다. 이 앱은 SQL을 실행하지 않습니다 — 문장만 만들어 드리니, 복사해서 DB 도구에 붙여넣고 실행하시면 됩니다.
1. 입력값 채우기
  • 최상위 지역 ID (up_area_id): 이 맵 전체를 가리키는 ID예요. 지역ID들의 공통 앞부분을 자동으로 넣어드리니 맞으면 그대로 두세요.
  • 출발점 지역 ID: 플레이어가 이 맵에서 처음 시작하는 지역의 ID. 모르면 비워두세요(전부 'N'으로 들어갑니다).
  • 재삽입 방식: 아래 3번 참고.
2. [생성] → [전체 복사] → DB 도구에 붙여넣기
HeidiSQL · DBeaver · phpMyAdmin · MySQL Workbench 같은 DB 관리 도구의 SQL 실행창에 붙여넣고 실행하세요. 실행 전에 올바른 데이터베이스가 선택돼 있는지, bot_area 테이블이 있는지 꼭 확인하세요.
3. '재삽입 방식'이 뭐예요?
  • INSERT IGNORE (기본·안전): 같은 지역ID가 이미 있으면 건너뜁니다. 실수로 두 번 실행해도 안전해요.
  • INSERT: 같은 지역ID가 이미 있으면 오류가 납니다(새로 넣을 때만).
  • ON DUPLICATE KEY UPDATE: 같은 지역ID가 있으면 최신 내용으로 덮어씁니다(수정 반영용).
4. 검증 리포트
생성 시 오류가 날 행을 미리 걸러내고 무엇이 문제인지 알려줍니다. 자주 나오는 것:
  • 길이 초과: 지역명·인접ID 등이 컬럼 한도(예: 100자)를 넘음 → 데이터를 줄이세요.
  • 4바이트 문자(이모지 등): 이 테이블은 utf8이라 이모지를 못 담아요 → 해당 글자를 빼거나, 테이블을 utf8mb4로 바꾸세요.
  • 숫자칸 오류: 목표치·골드·경험치 등 숫자 칸에 글자가 들어감 → 숫자만 남기세요.
걸러진 행은 SQL에 안 들어가므로 실행 시 오류가 나지 않습니다. 리포트에서 문제를 고친 뒤 다시 생성하면 됩니다.
5. 데이터가 아주 많다면
100행씩 나눠서 문장을 만듭니다. 그래도 실행 중 max_allowed_packet 오류가 나면 문장을 몇 개씩 나눠 실행하세요.
